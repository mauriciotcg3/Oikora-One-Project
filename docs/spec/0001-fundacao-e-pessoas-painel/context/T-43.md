## 2. Critérios de aceite e regras
- **CA-04** (P AC-004) Desfazer uma mesclagem faz as duas fichas voltarem a existir com os dados originais. — `docs/spec/0001-fundacao-e-pessoas-painel/spec.md:151`
- **CA-21** (P FR-016) A lista de possíveis duplicados mostra os pares que atendem à RN-23, e a mesclagem grava o valor escolhido em cada campo divergente. — `docs/spec/0001-fundacao-e-pessoas-painel/spec.md:168`
- **CA-22** (P FR-031; FLOW-009) A secretaria de destino pede a transferência e a de origem aprova ou recusa (com justificativa). Os dois resultados geram aviso e evento na linha do tempo. — `docs/spec/0001-fundacao-e-pessoas-painel/spec.md:169`
- **CA-07** (P AC-010) Uma pessoa excluída há menos de 30 dias pode ser recuperada da lixeira com todos os dados. — `docs/spec/0001-fundacao-e-pessoas-painel/spec.md:154`

## 4. Decisões que se aplicam (só a decisão)
- **OIK-ADR-0005 §6** — origem: `docs/adr/0005-auditoria-historico-e-operacoes-desfaziveis.md:62-62`
  > 6. **Operações desfazíveis (mesclagem e importação).** `operacoes_desfaziveis` (organização, tipo, autor, estado `executada|desfeita|expirada`, `expira_em` = execução + 90 dias) com o **snapshot** do estado anterior de cada registro afetado (sensíveis cifrados com a chave de campos do OIK-ADR-0004) e a lista do que foi criado ou movido (vínculos, relacionamentos, funções, eventos, conta). Desfazer é uma Action de compensação, auditada: recria a ficha absorvida, devolve o que foi movido e restaura cada campo **só se o valor atual ainda é o que a operação gravou**; se alguém mudou depois, mantém o atual e mostra o conflito à secretaria. Depois do prazo, um job apaga o snapshot e a operação fica só na auditoria. A importação por planilha (fora do MVP) e a carga da migração usam o mesmo mecanismo; o ensaio e a repetição da migração são do OIK-ADR-0009.
- **OIK-ADR-0006 §6** — origem: `docs/adr/0006-frontend-web.md:58-58`
  > 6. **Componentes e acessibilidade:** MUI 7 e MUI X DataGrid na versão MIT (sem Fuse, sem licença Pro); primitivos de design em `shared/ui/` com um `index.ts` por componente. Meta WCAG 2.2 AA (NFR-006), com `eslint-plugin-jsx-a11y`; ferramenta de teste automatizado de acessibilidade no OIK-ADR-0010. Exclusão só em menu de ações, com confirmação (lixeira de 30 dias do OIK-ADR-0005).

## 5. Rules aplicáveis (ID + frase)
Fonte: `.agents/rules/` da governança (localizar por ID; matriz em `.agents/rules/README.md`).
- **FE-GOV-001** — Identify the owning module, the API contract, and the operational impact before implementing a screen or flow.
- **FE-MOD-001** — A feature under `src/features/<Module>/` corresponds to the Laravel module `Modules/<Module>/` that owns the business rule shown on screen.
- **FE-MOD-003** — Code outside a feature imports exclusively from `features/<Module>/index.ts`.
- **FE-MOD-004** — Organize code in the owner feature and use only the segments (`api/`, `ui/`, `model/`, `lib/`, `types/`) the requirement needs.
- **FE-DEP-001** — Dependencies flow `shared → features → pages → app`.
- **FE-COMM-001** — Every call to the Laravel API goes through `shared/http/`. Do not instantiate an ad hoc HTTP client per component or feature.
- **FE-FLOW-001** — Components in `ui/` receive data and callbacks; they do not call `fetch`, axios, or an HTTP client directly.
- **FE-SEC-001** — Client-side validation and authorization are auxiliary; the backend always revalidates.
- **FE-TYPE-001** — `any` is forbidden. Exported function parameters and return types must be explicit; API contracts are typed from the approved spec.
- **FE-TEST-001** — A UI behavior change requires tests asserting what the user sees and can do, using React Testing Library.
- **FE-QUAL-001** — Run `tsc --noEmit` in strict mode and the configured lint before completion; do not suppress an error merely to pass the check.
- **FE-QUAL-003** — A frontend change does not integrate if it fails an applicable gate (types, architectural lint, tests).
- **FE-STATE-001** — Keep server state (API data, cache, invalidation, retry) and UI state (local selection, modal, filters) in separate abstractions.
- **CTX-001–011** — orçamento de contexto (sempre): uma task por sessão, Context Pack antes de documento, leitura dirigida, sem polling, saída enxuta.
