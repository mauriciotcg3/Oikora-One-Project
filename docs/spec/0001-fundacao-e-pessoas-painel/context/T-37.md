## 4. Decisões que se aplicam (só a decisão)
- **OIK-ADR-0006 §1** — origem: `docs/adr/0006-frontend-web.md:53-53`
  > 1. **Estrutura.** Workspace pnpm na raiz do `Oikora-One-Project` com `api/` (Laravel), `web/` (as duas entradas) e `packages/api-contrato/`; o app das lojas entra como `app/` no OIK-ADR-0007. Nomes finais de pastas na Spec. `web/` é um único projeto Vite (React 19+, TypeScript strict; versões na Spec) com duas entradas HTML — `painel` e `membro` (área do membro + formulários públicos) — e duas raízes em `app/` (roteador, providers, Error Boundary de cada entrada). Features seguem o Frontend Standard (`features/<Modulo>/` = módulo Laravel, Public API em `index.ts`, `shared/` sem dono de negócio); a separação dos bundles vem do grafo de imports, e um orçamento de tamanho por entrada é verificado no CI (OIK-ADR-0010).
- **OIK-ADR-0006 §3** — origem: `docs/adr/0006-frontend-web.md:55-55`
  > 3. **Roteamento:** TanStack Router. Filtros, página, tamanho de página e ordenação das listas ficam na URL, com parâmetros tipados e validados; links e "voltar" preservam a lista. Rotas carregam features por import dinâmico (FE-PERF-002).
- **OIK-ADR-0006 §4** — origem: `docs/adr/0006-frontend-web.md:56-56`
  > 4. **Dados:** TanStack Query para estado de servidor; chaves de consulta incluem a organização ativa. Sem Redux, Zustand ou estado global; Context só em `app/` para sessão, organização ativa e tema. Mutations invalidam as consultas da feature dona.
- **OIK-ADR-0006 §5** — origem: `docs/adr/0006-frontend-web.md:57-57`
  > 5. **Formulários:** React Hook Form + Zod, só para experiência (FE-SEC-001). Um helper de `shared/` converte o 422 do Laravel (`errors` por caminho, ex.: `contatos.0.valor`) em erro no campo, leva o foco ao primeiro erro e mostra num resumo os erros de campos que não estão na tela. Mensagens do servidor chegam no idioma da conta; as do cliente vêm dos arquivos de tradução.
- **OIK-ADR-0006 §10** — origem: `docs/adr/0006-frontend-web.md:62-62`
  > 10. **Sessão (OIK-ADR-0003).** Todo pedido sai por `shared/http/` com `credentials: include` e `X-XSRF-TOKEN` lido do cookie. **419:** renova o cookie CSRF e repete uma vez. **401:** limpa o cache e vai ao login com a URL de volta. **Elevação expirada** (403 com `codigo: elevacao_necessaria`): diálogo de senha + 2FA sobre a tela atual, sem perder o formulário, e repetição do pedido. **Troca de organização:** chama a API, limpa todo o cache e recarrega a entrada. **Várias abas:** todo pedido envia `X-Organizacao-Esperada`; se divergir da organização ativa no servidor, a API responde 409 `organizacao_trocada` sem executar nada e a aba recarrega; `BroadcastChannel` avisa as outras abas. O cabeçalho só confere, nunca escolhe a organização.
- **OIK-ADR-0006 §11** — origem: `docs/adr/0006-frontend-web.md:63-63`
  > 11. **Contrato de erro:** 422 no formato padrão do Laravel (`message`, `errors` por campo); demais erros com `codigo` estável (`elevacao_necessaria`, `organizacao_trocada` etc.); lista fechada na Spec.
- **OIK-ADR-0006 §13** — origem: `docs/adr/0006-frontend-web.md:65-65`
  > 13. **Idioma:** i18next com namespaces por feature; só `pt-BR` no MVP; nenhum texto fixo em componente; novo idioma = novo arquivo. Datas e números por `Intl`; telefone com `libphonenumber-js` (E.164, OIK-ADR-0003).
- **OIK-ADR-0006 §14** — origem: `docs/adr/0006-frontend-web.md:66-66`
  > 14. **Observabilidade:** OpenTelemetry no navegador conforme o Frontend Standard §15; todo pedido envia `X-Cliente: painel|membro@<versão do build>`; Error Boundary mostra e registra o `trace_id`. Exportador, coletor e retenção no OIK-ADR-0010.

## 5. Rules aplicáveis (ID + frase)
Fonte: `.agents/rules/` da governança (localizar por ID; matriz em `.agents/rules/README.md`).
- **FE-GOV-001** — Identify the owning module, the API contract, and the operational impact before implementing a screen or flow.
- **FE-MOD-001** — A feature under `src/features/<Module>/` corresponds to the Laravel module `Modules/<Module>/` that owns the business rule shown on screen.
- **FE-MOD-003** — Code outside a feature imports exclusively from `features/<Module>/index.ts`.
- **FE-MOD-004** — Organize code in the owner feature and use only the segments (`api/`, `ui/`, `model/`, `lib/`, `types/`) the requirement needs.
- **FE-DEP-001** — Dependencies flow `shared → features → pages → app`.
- **FE-COMM-001** — Every call to the Laravel API goes through `shared/http/`. Do not instantiate an ad hoc HTTP client per component or feature.
- **FE-FLOW-001** — Components in `ui/` receive data and callbacks; they do not call `fetch`, axios, or an HTTP client directly.
- **FE-SEC-001** — Client-side validation and authorization are auxiliary; the backend always revalidates.
- **FE-TYPE-001** — `any` is forbidden. Exported function parameters and return types must be explicit; API contracts are typed from the approved spec.
- **FE-TEST-001** — A UI behavior change requires tests asserting what the user sees and can do, using React Testing Library.
- **FE-QUAL-001** — Run `tsc --noEmit` in strict mode and the configured lint before completion; do not suppress an error merely to pass the check.
- **FE-QUAL-003** — A frontend change does not integrate if it fails an applicable gate (types, architectural lint, tests).
- **FE-MOD-005** — Add to `shared/` only when the code has no clear feature owner and is genuinely reused.
- **FE-STATE-001** — Keep server state (API data, cache, invalidation, retry) and UI state (local selection, modal, filters) in separate abstractions.
- **FE-OBS-002** — Never log passwords, full tokens, cookies, or unnecessary PII.
- **FE-OBS-003** — Initialize OpenTelemetry in `app/` before rendering and propagate `traceparent`/`tracestate` through `shared/http/`.
- **FE-PERF-002** — Load a feature's Public API via dynamic import per route when bundle size justifies it.
- **FE-QUAL-002** — Feature Boundary, Public API, dependency direction, and the single HTTP client must be enforceable by ESLint/Steiger or an equivalent CI check.
- **CTX-001–011** — orçamento de contexto (sempre): uma task por sessão, Context Pack antes de documento, leitura dirigida, sem polling, saída enxuta.
